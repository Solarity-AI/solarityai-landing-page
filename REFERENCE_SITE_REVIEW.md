# Solarity AI reference website review

Review date: October 12, 2026, America/Chicago.

Status: **technical planning documentation, not visitor-facing content**. All redesign opportunities and effect adaptations in this document are **PROPOSED, NOT IMPLEMENTED**. The only separately authorized implementation in this request is replacing Voice Max with Fitness Max and keeping the consumer portfolio to 4 apps. This review does not establish whether that separate change has been deployed.

The strongest direction is to retain the current GPT Site's investor and strategic partner structure, authentic product evidence, and lightweight delivery, then selectively borrow the original site's authentic company identity and the demo's visual hierarchy, product compositions, and restrained interaction ideas. The demo's claims, placeholder screens, and full animation stack should not be imported as evidence or production requirements.

Current Site: [Solarity AI on GPT Sites](https://solarity-company.the-ata-turhan.chatgpt.site/).

## Performance and accessibility constraints for any later implementation

Sources: [shared JavaScript](https://demosolarity.drubleat.dev/assets/pixels-CRVU0_rH.js), [shared CSS](https://demosolarity.drubleat.dev/assets/pixels-CUzVFnP1.css), [Home JavaScript](https://demosolarity.drubleat.dev/assets/main-Dhg0IlT3.js), [Applications JavaScript](https://demosolarity.drubleat.dev/assets/applications-5Mn8bL4G.js).

- **Reduced motion is only partially implemented in the demo.** The loader, Lenis, cursor, magnetic behavior, floating phones, desktop dot grids, team follower, and some parallax effects are guarded. Split/reveal effects, marquee ticker, homepage particle canvas, horizontal pinning, card stacking, counters, and footer animation still run. CSS duration overrides do not stop JavaScript tweens.
- **Continuous loops are not visibility-gated in the audited application code.** The wordmark particles, dot grids, and marquee can continue working while outside the viewport. Prefer no continuous animation; otherwise suspend it when offscreen or the document is hidden.
- **The animation stack has a material source size.** Shared JavaScript is 156,348 bytes uncompressed. Route totals are 160,927 bytes for Home, 169,499 for Applications, and 158,309 for Team. These are retrieved source sizes, not transferred-byte measurements or Lighthouse results.
- **The demo requests 4 font families and 12 variants.** Space Grotesk, Inter Tight, JetBrains Mono, and Instrument Serif. A restrained typographic adaptation should preserve the current Site's performance budget.
- **Faint labels need stronger contrast.** The source token `#f5f2ec52` over base `#05060a` produces approximately 2.59:1 contrast by calculation. It is used for small metadata and role labels. This calculation describes the token on the base surface, not every rendered element.
- **Mobile navigation logic should not be copied wholesale.** The demo source sets `aria-expanded`, but does not implement Escape dismissal, focus trapping/restoration, `aria-controls`, or inert background management in its drawer code.
- **Keep native links functional.** The curtain handler does not check Ctrl, Cmd, or Shift modifiers before intercepting internal clicks. Any future progressive enhancement must preserve native navigation behavior.
- **Do not show false interaction cues.** Demo team cards are noninteractive articles but reveal outward-link-style arrows on hover. Only show link affordances when there is an actual destination.
- **Retain a usable static baseline.** The demo's fixed first-visit preloader is removed by JavaScript and has no noscript fallback. Current essential content and navigation should remain readable without animation scripts.
- **Preserve mobile layout stability.** Keep image dimensions, stable header geometry, and the existing pre-paint navigation setup. No proposed effect should reintroduce the previously investigated mobile layout shift.

Future validation should compare actual mobile and desktop layouts, keyboard behavior, reduced-motion behavior, first-load visibility, layout shift, and fresh PageSpeed results before and after a chosen design package. No fresh Lighthouse score or guarantee of unchanged scores is provided by this reference review.
